1. \(\int x \cos x dx\)

đặt \(u = x \Rightarrow du = dx\)

đặt \(dv = \cos x dx \Rightarrow v = \sin x\)

Thế vô ta được I \(= x \sin x - \int \sin x dx\)

\(= x \sin x + \cos x + C\)

2. \(\int x^3 \ln x dx\)

đặt \(u = \ln x \Rightarrow du = \frac{1}{x}dx\)

đặt \(dv = x^3 dx \Rightarrow v = \frac{x^4}{4}\)

Thế vô ta được I \(= \frac{x^4}{4} \ln x - \int \frac{x^3}{4} dx\)

\(= \frac{x^4}{4} \ln x - \frac{x^4}{16} + C\)

3. \(\int \arctan x dx\)

đặt \(u = \arctan x \Rightarrow du = \frac{1}{1+x^2}dx\)

đặt \(dv = dx \Rightarrow v = x\)

Thế vô ta được I \(= x \arctan x - \int \frac{x}{1+x^2} dx\)

\(= x \arctan x - \frac{1}{2} \ln(1+x^2) + C\)

4. \(\int x^2 \arctan x dx\)

đặt \(u = \arctan x \Rightarrow du = \frac{1}{1+x^2}dx\)

đặt \(dv = x^2 dx \Rightarrow v = \frac{x^3}{3}\)

Thế vô ta được I \(= \frac{x^3}{3} \arctan x - \frac{1}{3} \int \frac{x^3}{1+x^2} dx\)

\(= \frac{x^3}{3} \arctan x - \frac{1}{3} \int (x - \frac{x}{1+x^2}) dx\)

\(= \frac{x^3}{3} \arctan x - \frac{x^2}{6} + \frac{1}{6} \ln(1+x^2) + C\)

5. \(\int \frac{x e^x}{(x+1)^2} dx\)

đặt \(u = x e^x \Rightarrow du = (e^x + x e^x)dx = e^x(x+1)dx\)

đặt \(dv = \frac{1}{(x+1)^2} dx \Rightarrow v = -\frac{1}{x+1}\)

Thế vô ta được I \(= -\frac{x e^x}{x+1} - \int -\frac{1}{x+1} \cdot e^x(x+1)dx\)

\(= -\frac{x e^x}{x+1} + \int e^x dx = -\frac{x e^x}{x+1} + e^x + C = \frac{e^x}{x+1} + C\)

6. \(\int (x^2+1)e^{-2x}dx\)

đặt \(u = x^2+1 \Rightarrow du = 2xdx\)

đặt \(dv = e^{-2x}dx \Rightarrow v = -\frac{1}{2}e^{-2x}\)

Từng phần tiếp cụm sau ta được kết quả thu gọn:

\(= e^{-2x} (-\frac{1}{2}x^2 - \frac{1}{2}x - \frac{3}{4}) + C\)

7. \(\int e^{-2x} \cos 3x dx\)

đặt \(u = \cos 3x \Rightarrow du = -3\sin 3xdx\)

đặt \(dv = e^{-2x}dx \Rightarrow v = -\frac{1}{2}e^{-2x}\)

Nguyên hàm từng phần 2 lần xuất hiện lại chính nó (vòng lặp):

\(= \frac{e^{-2x}}{13} (3\sin 3x - 2\cos 3x) + C\)

8. \(\int \frac{x e^{\arctan x}}{\sqrt{(1+x^2)^3}} dx\)

đổi biến trước: đặt \(t = \arctan x \Rightarrow dt = \frac{1}{1+x^2}dx\)

Phương trình thành \(\int e^t \sin t dt\), dùng từng phần vòng lặp:

\(= \frac{1}{2} e^t (\sin t - \cos t) + C\)

\(= \frac{1}{2}e^{\arctan x} \cdot \frac{x-1}{\sqrt{1+x^2}} + C\)

9. \(\int \frac{x \arcsin x}{\sqrt{1-x^2}} dx\)

đặt \(u = \arcsin x \Rightarrow du = \frac{1}{\sqrt{1-x^2}}dx\)

đặt \(dv = \frac{x}{\sqrt{1-x^2}}dx \Rightarrow v = -\sqrt{1-x^2}\)

Thế vô ta được I \(= -\sqrt{1-x^2}\arcsin x + \int 1 dx\)

\(= -\sqrt{1-x^2}\arcsin x + x + C\)

10. \(\int x (\arctan x)^2 dx\)

đặt \(u = (\arctan x)^2 \Rightarrow du = \frac{2\arctan x}{1+x^2}dx\)

đặt \(dv = x dx \Rightarrow v = \frac{x^2}{2}\)

Thế vô ráp kết quả từ câu 3 và câu nâng cao:

\(= \frac{x^2+1}{2}(\arctan x)^2 - x\arctan x + \frac{1}{2}\ln(1+x^2) + C\)

11. \(\int \frac{\sqrt{1-x^2}}{x^3}dx\)

đặt \(u = \sqrt{1-x^2} \Rightarrow du = -\frac{x}{\sqrt{1-x^2}}dx\)

đặt \(dv = \frac{1}{x^3}dx \Rightarrow v = -\frac{1}{2x^2}\)

Thế vô biến đổi tiếp thu được kết quả:

\(= -\frac{\sqrt{1-x^2}}{2x^2} + \frac{1}{2}\ln\left|\frac{1+\sqrt{1-x^2}}{x}\right| + C\)

12. \(\int \sin (\ln x)dx\)

đặt \(u = \sin(\ln x) \Rightarrow du = \frac{\cos(\ln x)}{x}dx\)

đặt \(dv = dx \Rightarrow v = x\)

Nguyên hàm từng phần lần 2 xuất hiện lại vòng lặp:

\(= \frac{x}{2} (\sin(\ln x) - \cos(\ln x)) + C\)
