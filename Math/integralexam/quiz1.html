1. \(\int \frac{x}{4+x^2}dx\)

đặt t = \(4+x^2 \Rightarrow dt = 2x.dx \Rightarrow x.dx = \frac{1}{2}dt\)

Thế vô phương trình ta được I = \(\int \frac{1}{t} \frac{1}{2}dt\)

\(= \frac{1}{2} \ln (t) + C\)

\(= \frac{1}{2} \ln (4+x^2) + C\)

2. \(\int \frac{x}{\sqrt{1-x^4}}dx\)

\(= \int \frac{x}{\sqrt{1-(x^2)^2}}dx\)

đặt t \(= x^2 \Rightarrow dt = 2x.dx \Rightarrow x.dx = \frac{1}{2}dt\)

Thế vô phương trình ta được I \(= \int \frac{1}{2} \frac{1}{\sqrt{1-t^2}}dt\)

\(= \frac{1}{2} \arcsin t + C = \frac{1}{2} \arcsin x^2+ C\)

3. \(\int 3^{4x} dx\)

đặt t = \(4x \Rightarrow dt = 4.dx \Rightarrow dx = \frac{1}{4}dt\)

Thế vô phương trình ta được I \(= \int 3^t \frac{1}{4}dt\)

\(= \frac{1}{4} \frac{3^t}{\ln 3} + C\)

\(= \frac{3^{4x}}{4\ln 3} + C\)

4. \(\int \frac{1}{x \ln ^2 x} dx\)

đặt t = \(\ln x \Rightarrow dt = \frac{1}{x}dx\)

Thế vô phương trình ta được I \(= \int \frac{1}{t^2} dt = \int t^{-2} dt\)

\(= \frac{t^{-1}}{-1} + C = -\frac{1}{t} + C\)

\(= -\frac{1}{\ln x} + C\)

5. \(\int \frac{\sin x}{\sqrt{4+\cos^2x}} dx\)

đặt t = \(\cos x \Rightarrow dt = -\sin x.dx \Rightarrow \sin x.dx = -dt\)

Thế vô phương trình ta được I \(= \int \frac{-1}{\sqrt{4+t^2}} dt\)

\(= -\ln(t + \sqrt{4+t^2}) + C\)

\(= -\ln(\cos x + \sqrt{4+\cos^2x}) + C\)

6. \(\int \frac{3x^2}{\sqrt{x^6+1}}dx\)

\(= \int \frac{3x^2}{\sqrt{(x^3)^2+1}}dx\)

đặt t = \(x^3 \Rightarrow dt = 3x^2.dx\)

Thế vô phương trình ta được I \(= \int \frac{1}{\sqrt{t^2+1}} dt\)

\(= \ln|t + \sqrt{t^2+1}| + C\)

\(= \ln(x^3 + \sqrt{x^6+1}) + C\)

7. \(\int \frac{1}{4x^2+7}dx\)

\(= \int \frac{1}{(2x)^2+(\sqrt{7})^2}dx\)

đặt t = \(2x \Rightarrow dt = 2.dx \Rightarrow dx = \frac{1}{2}dt\)

Thế vô phương trình ta được I \(= \int \frac{1}{t^2+(\sqrt{7})^2} \frac{12}dt\)

\(= \frac{1}{2} \cdot \frac{1}{\sqrt{7}} \arctan(\frac{t}{\sqrt{7}}) + C = \frac{1}{2\sqrt{7}} \arctan(\frac{2x}{\sqrt{7}}) + C\)

8. \(\int \frac{x}{4x^2+7} dx\)

đặt t = \(4x^2+7 \Rightarrow dt = 8x.dx \Rightarrow x.dx = \frac{1}{8}dt\)

Thế vô phương trình ta được I \(= \int \frac{1}{t} \frac{1}{8}dt\)

\(= \frac{1}{8} \ln|t| + C\)

\(= \frac{1}{8} \ln(4x^2+7) + C\)

9. \(\int \frac{e^x}{\sqrt{e^{2x}-1}} dx\)

\(= \int \frac{e^x}{\sqrt{(e^x)^2-1}} dx\)

đặt t = \(e^x \Rightarrow dt = e^x.dx\)

Thế vô phương trình ta được I \(= \int \frac{1}{\sqrt{t^2-1}} dt\)

\(= \ln|t + \sqrt{t^2-1}| + C = \ln(e^x + \sqrt{e^{2x}-1}) + C\)

10. \(\int \frac{1}{2^x+1} dx\)

\(= \int \frac{2^x+1-2^x}{2^x+1} dx = \int (1 - \frac{2^x}{2^x+1}) dx\)

đặt t = \(2^x+1 \Rightarrow dt = 2^x \ln 2.dx \Rightarrow 2^x.dx = \frac{dt}{\ln 2}\)

Thế vô phương trình ta được I \(= x - \int \frac{1}{t} \frac{dt}{\ln 2}\)

\(= x - \frac{1}{\ln 2} \ln|t| + C = x - \frac{\ln(2^x+1)}{\ln 2} + C\)

11. \(\int \frac{1}{\sin x \cos x}dx\)

\(= \int \frac{\sin^2x + \cos^2x}{\sin x \cos x}dx = \int (\frac{\sin x}{\cos x} + \frac{\cos x}{\sin x})dx\)

\(= \int \tan x dx + \int \cot x dx\)

\(= -\ln|\cos x| + \ln|\sin x| + C\)

\(= \ln|\tan x| + C\)

12. \(\int \frac{1}{x+\sqrt{x}}dx\)

\(= \int \frac{1}{\sqrt{x}(\sqrt{x}+1)}dx\)

đặt t = \(\sqrt{x}+1 \Rightarrow dt = \frac{1}{2\sqrt{x}}dx \Rightarrow \frac{1}{\sqrt{x}}dx = 2dt\)

Thế vô phương trình ta được I \(= \int \frac{1}{t} \cdot 2dt\)

\(= 2\ln|t| + C = 2\ln(\sqrt{x}+1) + C\)
