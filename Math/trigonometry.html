Định nghĩa cơ bản:

\(\bullet \tan x = \frac{\sin x}{\cos x}\)

\(\bullet \cot x = \frac{\cos x}{\sin x}\)

Công thức hệ thức cơ bản:

\(\bullet \sin ^2 x + \cos ^2 x = 1\)

\(\bullet \tan x \cdot \cot x = 1\)

\(\bullet 1+ \tan ^2 x = \frac{1}{\cos ^2 x}\)

\(\bullet 1+ \cot ^2 x = \frac{1}{\sin ^2 x}\)

Công thức cộng:

\(\bullet \sin (x \pm y) = \sin x \cos y \pm \cos x \sin y\)

\(\bullet \cos (x \pm y) = \cos x \cos y \mp \sin x \sin y\)

\(\bullet \tan (x \pm y) = \frac{\tan x \pm \tan y}{1 \mp \tan x \tan y}\)

Công thức nhân đôi & Nhân ba:

\(\bullet \sin 2x = 2 \sin x \cos x\)

\(\bullet \cos 2x = \cos ^2 x - \sin ^2 x = 2 \cos ^2 x - 1 = 1 - 2 \sin ^2 x\)

\(\bullet \tan 2x = \frac{2 \tan x}{1 - \tan ^2 x}\)

\(\bullet \sin 3x = 3 \sin x - 4 \sin ^3 x\)

\(\bullet \cos 3x = 4 \cos ^3 x - 3 \cos x\)

Công thức hạ bậc:

\(\bullet \sin ^2 x = \frac{1 - \cos 2x}{2}\)

\(\bullet \cos ^2 x = \frac{1 + \cos 2x}{2}\)

\(\bullet \tan ^2 x = \frac{1 - \cos 2x}{1 + \cos 2x}\)

Công thức biến đổi tích thành tổng:

\(\bullet \cos x \cos y = \frac{1}{2} [\cos(x - y) + \cos(x + y)]\)

\(\bullet \sin x \sin y = \frac{1}{2} [\cos(x - y) - \cos(x + y)]\)

\(\bullet \sin x \cos y = \frac{1}{2} [\sin(x - y) + \sin(x + y)]\)

Công thức biến đổi tổng thành tích:

\(\bullet \cos x + \cos y = 2 \cos \frac{x + y}{2} \cos \frac{x - y}{2}\)

\(\bullet \cos x - \cos y = -2 \sin \frac{x + y}{2} \sin \frac{x - y}{2}\)

\(\bullet \sin x + \sin y = 2 \sin \frac{x + y}{2} \cos \frac{x - y}{2}\)

\(\bullet \sin x - \sin y = 2 \cos \frac{x + y}{2} \sin \frac{x - y}{2}\)
