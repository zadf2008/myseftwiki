Tích phân

Tính chất:

\(\bullet \int 0 \, dx = C\)

\(\bullet \int k \cdot f(x) dx = k \int f(x) dx \quad (k \ne 0)\)

\(\bullet \int [f(x) \pm g(x)] dx = \int f(x) dx \pm \int g(x) dx\)

\(\bullet \int_{a}^{b} f(x) dx = F(b) - F(a) = F(x) \Big|_a^b\)

\(\bullet \int_{a}^{b} f(x) dx = \int_{a}^{c} f(x) dx + \int_{c}^{b} f(x) dx\)

\(\bullet \int_{a}^{b} f(x) dx = -\int_{b}^{a} f(x) dx \Rightarrow \int_{a}^{a} f(x) dx = 0\)

Phương pháp cốt lõi:

\(\bullet \text{Đổi biến số (Dạng 1): } \int f[\phi(x)]\cdot\phi'(x)dx = \int f(u)du \quad (\text{với } u = \phi(x))\)

\(\bullet \text{Tích phân từng phần: } \int u \, dv = u \cdot v - \int v \, du \Rightarrow \int_{a}^{b} u \, dv = (u \cdot v) \Big|_a^b - \int_{a}^{b} v \, du\)

Công thức tích phân nhanh:

\(\bullet \int \frac{dx}{(x-a)(x-b)} = \frac{1}{a-b} \ln \left| \frac{x-a}{x-b} \right| + C\)

\(\bullet \int \frac{ax+b}{cx+d} dx = \frac{a}{c}x + \frac{bc-ad}{c^2}\ln|cx+d| + C\)

\(\bullet \int \frac{dx}{a\sin x + b\cos x} = \frac{1}{\sqrt{a^2+b^2}} \ln \left| \tan \left( \frac{x + \arctan(b/a)}{2} \right) \right| + C\)

\(\bullet \int e^{ax}\sin(bx) dx = \frac{e^{ax}(a\sin bx - b\cos bx)}{a^2+b^2} + C\)

\(\bullet \int e^{ax}\cos(bx) dx = \frac{e^{ax}(a\cos bx + b\sin bx)}{a^2+b^2} + C\)

Công thức tích phân

Hàm số \(f(x)\) Nguyên hàm \(\int f(x)dx\) Hàm hợp \(f(u)\) với \(u=u(x)\) Tích phân nâng cao / Mở rộng
\(e^x\) \(e^x + C\) \(\int e^u du = e^u + C\) \(\int e^{ax+b} dx = \frac{1}{a}e^{ax+b} + C\)
\(\ln x\) \(x \ln x - x + C\) \(\int \ln u du = u \ln u - u + C\) \(\int x^n \ln x dx = \frac{x^{n+1}}{n+1}\ln x - \frac{x^{n+1}}{(n+1)^2} + C\)
\(\frac{1}{x} \quad (x \ne 0)\) \(\ln|x| + C\) \(\int \frac{1}{u} du = \ln|u| + C\) \(\int \frac{1}{ax+b} dx = \frac{1}{a}\ln|ax+b| + C\)
\(x^a \quad (a \ne -1)\) \(\frac{x^{a+1}}{a+1} + C\) \(\int u^a du = \frac{u^{a+1}}{a+1} + C\) \(\int (ax+b)^r dx = \frac{1}{a} \cdot \frac{(ax+b)^{r+1}}{r+1} + C\)
\(a^x \quad (a>0, a\ne1)\) \(\frac{a^x}{\ln a} + C\) \(\int a^u du = \frac{a^u}{\ln a} + C\) \(\int a^{kx+m} dx = \frac{1}{k} \cdot \frac{a^{kx+m}}{\ln a} + C\)
\(\frac{1}{\sqrt{x}}\) \(2\sqrt{x} + C\) \(\int \frac{1}{\sqrt{u}} du = 2\sqrt{u} + C\) \(\int \frac{1}{\sqrt{ax+b}} dx = \frac{2}{a}\sqrt{ax+b} + C\)
\(\sin x\) \(-\cos x + C\) \(\int \sin u du = - \cos u + C\) \(\int \sin(ax+b) dx = -\frac{1}{a}\cos(ax+b) + C\)
\(\cos x\) \(\sin x + C\) \(\int \cos u du = \sin u + C\) \(\int \cos(ax+b) dx = \frac{1}{a}\sin(ax+b) + C\)
\(\frac{1}{\cos^2 x}\) \(\tan x + C\) \(\int \frac{1}{\cos^2 u} du = \tan u + C\) \(\int \frac{1}{\cos^2(ax+b)} dx = \frac{1}{a}\tan(ax+b) + C\)
\(\frac{1}{\sin^2 x}\) \(-\cot x + C\) \(\int \frac{1}{\sin^2 u} du = -\cot u + C\) \(\int \frac{1}{\sin^2(ax+b)} dx = -\frac{1}{a}\cot(ax+b) + C\)
\(\frac{1}{x^2 + a^2}\) \(\frac{1}{a} \arctan \frac{x}{a} + C\) \(\int \frac{1}{u^2 + a^2} du = \frac{1}{a} \arctan \frac{u}{a} + C\) \(\int \frac{1}{\sqrt{a^2 - x^2}} dx = \arcsin \frac{x}{a} + C\)
\(\frac{1}{x^2 - a^2}\) \(\frac{1}{2a} \ln \left| \frac{x-a}{x+a} \right| + C\) \(\int \frac{1}{u^2 - a^2} du = \frac{1}{2a} \ln \left| \frac{u-a}{u+a} \right| + C\) \(\int \frac{1}{\sqrt{x^2 \pm a^2}} dx = \ln \left| x + \sqrt{x^2 \pm a^2} \right| + C\)

Tích phân suy rộng loại 1 & Tiêu chuẩn hội tụ

Định lý chuẩn (Mẫu) Tiêu chuẩn so sánh 1 (Bất đẳng thức) Tiêu chuẩn so sánh 2 (Giới hạn - Lim) Tiêu chuẩn Abel / Dirichlet
\(\int_{a}^{+\infty} \frac{dx}{x^\alpha} \quad (a > 0)\)

\(\bullet \text{ Hội tụ nếu } \alpha > 1\)
\(\bullet \text{ Phân kỳ nếu } \alpha \le 1\) 		Cho \(0 \le f(x) \le g(x)\):

\(\bullet \int_{a}^{+\infty} g(x)dx \text{ hội tụ} \Rightarrow \int_{a}^{+\infty} f(x)dx \text{ hội tụ}\)
\(\bullet \int_{a}^{+\infty} f(x)dx \text{ phân kỳ} \Rightarrow \int_{a}^{+\infty} g(x)dx \text{ phân kỳ}\) 		Xét \(k = \lim_{x \to +\infty} \frac{f(x)}{g(x)} \quad (f, g \ge 0)\):

\(\bullet \text{Nếu } 0 < k < +\infty\): 2 tích phân cùng hội tụ hoặc cùng phân kỳ.
\(\bullet \text{Nếu } k = 0\): \(g(x)\) hội tụ \(\Rightarrow f(x)\) hội tụ.
\(\bullet \text{Nếu } k = +\infty\): \(g(x)\) phân kỳ \(\Rightarrow f(x)\) phân kỳ. 		\(\int_{a}^{+\infty} f(x) \cdot g(x) \, dx\)

\(\bullet \text{Dirichlet: } f(x) \text{ liên tục, đơn điệu và } \lim_{x \to +\infty} f(x) = 0\); còn \(g(x)\) có nguyên hàm bị chặn. \(\Rightarrow\) Hội tụ.
