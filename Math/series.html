Chuỗi số

\(\bullet\) Chuỗi số là một chuỗi các số hạng số thực liên tiếp nhau

\(\bullet\) Dạng tổng quát: \(\sum\limits_{n=1}^{k} u_n\)

- k là một số nguyên dương khác 0

- \(u_n\) là số hạng thứ n của chuỗi số (giống như một hàm f(n) tại n vậy)

\(\bullet\) Chuỗi số được gọi là chuỗi số dương khi mọi \(u_n > 0\)

Các tiêu chuẩn so sánh:

\(\bullet\) Tiêu chuẩn so sánh Cauchy-Maclaurin

- \(\sum\limits_{n=1}^{k} f(n)\) hội tụ \(\Leftrightarrow \int_{1}^{\infty} f(x)\) hội tụ

\(\bullet\) Tiêu chuẩn so sánh 1:

Hai chuỗi số dương \(\sum\limits_{n=1}^{\infty} u_n\) và \(\sum\limits_{n=1}^{\infty} v_n\) cùng hội tụ khi \(v_n < u_n\)

\(\bullet\) Tiêu chuẩn so sánh 2:

- Hai chuỗi số dương \(\sum\limits_{n=1}^{\infty} u_n\) và \(\sum\limits_{n=1}^{\infty} v_n\), xét K = \(\underset{n \to +\infty}{\lim} \frac{u_n}{v_n}\)

+ K = 0 thì cả 2 chuỗi số hội tụ

+ 0 < K < \(\infty\) thì cả hai hoặc phân kỳ hoặc hội tụ

+ K = \(+\infty\) và \(\sum\limits_{n=1}^{\infty} v_n\) phân kỳ thì \(\sum\limits_{n=1}^{\infty} u_n\) cũng phân kỳ

\(\bullet\) Tiêu chuẩn d'Alembert:

- Cho chuỗi dương \(\sum\limits_{n=1}^{+\infty} u_n\) với \(\underset{n \to +\infty}{\lim} \frac{u_{n+1}}{u_n}\) = D

+ D < 1 thì chuỗi hội tụ

+ D > 1 thì chuỗi phân kỳ

\(\bullet\) Tiêu chuẩn Cauchy:

- Cho chuỗi dương \(\sum\limits_{n=1}^{+\infty} u_n\) với \(\underset{n \to +\infty}{\lim} \sqrt[n]{u_n}\) = C

+ C < 1 thì chuỗi hội tụ

+ C > 1 thì chuỗi phân kỳ

\(\bullet\) Tiêu chuẩn Leibniz:

- Cho chuỗi số đan xen \(\sum\limits_{n=1}^{+\infty} (-1)^{n+1}u_n\) và \(u_n\) tiến về 0 thì nó thỏa: \(u_1 - u_2 \leq S \leq u_1\)

\(\bullet\) Hội tụ tuyệt đối:

- Nếu \(\sum\limits_{n=1}^{+\infty} |u_n|\) hội tụ thì \(\sum\limits_{n=1}^{+\infty} u_n\) hội tụ và \(\sum\limits_{n=1}^{+\infty} |u_n| \leq \sum\limits_{n=1}^{+\infty} u_n\)
