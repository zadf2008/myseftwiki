Thông tin sơ bộ về MH-8:

Thông tin cơ bản:

\(\bullet\) Đây là 1 con đo xem có vật cản không bằng cách xem tia hồng ngoại có dội về không

\(\bullet\) Điện áp hoạt động: 5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân cảm biến-arduino)

- Chân +OUT nối với chân 7(hoặc bất kì chân digital nào của arduino)

- Cực dương(VCC) nối với đầu 5V

- Cực âm(GND) nối với đầu GND

- Code mẫu:

// Định nghĩa chân kết nối cảm biến MH 3 chân trên Arduino

const int sensorPin = 7; // Chân OUT/DO của cảm biến nối vào chân Digital 7

int sensorValue = 0; // Biến lưu trạng thái Digital (0 hoặc 1)

void setup() {

__pinMode(sensorPin, INPUT); // Cấu hình chân Digital 7 là Đầu Vào

__Serial.begin(9600); // Mở cổng Serial Monitor xem kết quả

}

void loop() {

__// Đọc trạng thái Digital từ cảm biến

__sensorValue = digitalRead(sensorPin);

__// Kiểm tra trạng thái phản hồi

__if (sensorValue == LOW) { // Đa số cảm biến dòng MH sẽ kéo chân OUT về mức LOW khi được kích hoạt

____Serial.println("Co vat can");

__} else {

____Serial.println("Trang thai: Binh thuong");

__}

__delay(200); // Đọc lại sau mỗi 0.2 giây để phản hồi nhanh chóng

}
