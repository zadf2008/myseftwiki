Thông tin sơ bộ về V182:

Thông tin cơ bản:

\(\bullet\) Đây là 1 con cảm biến đo cả độ ẩm và nhiệt độ trong không khí

\(\bullet\) Dải đo nhiệt độ: từ 0-50\(^oC\) (sai số \(\pm\)2%)

\(\bullet\) Dải đo độ ẩm: từ 20-90% RH (sai số \(\pm\)5%)

\(\bullet\) Điện áp hoạt động: 3.3-5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân cảm biến-arduino)

- Chân OUT nối với chân 2(hoặc bất kì chân digital nào của arduino, tuy nhiên tốt nhất nên cắm vô chân 2 hoặc chân 3 của arduino để tận dụng khả năng ngắt, tránh bị lỗi đọc dữ liệu và đọc ổn định hơn)

- Cực dương(+) nối với đầu 5V

- Cực âm(-) nối với đầu GND

- Tải thư viện: bấm vô Tools \(\rightarrow\) Manage Libraries \(\rightarrow\) tra thư viện tên "DHT sensor library" của tác giả "Adafruit" \(\rightarrow\) Install

- Code mẫu:

#include <DHT.h>

const int dhtPin = 2; // Chân out của cảm biến nối với chân Digital 2

#define DHTTYPE DHT11 // Khai báo loại cảm biến là DHT11

DHT dht(dhtPin, DHTTYPE);

void setup() {

__Serial.begin(9600);

__dht.begin(); // Khởi động cảm biến V182

}

void loop() {

__delay(2000); // Chờ 2 giây giữa các lần đo

__float h = dht.readHumidity(); // Đọc độ ẩm

__float t = dht.readTemperature(); // Đọc nhiệt độ

__if (isnan(h) || isnan(t)) {

____Serial.println("Lỗi: Không đọc được dữ liệu từ cảm biến V182!");

____return;

__}

__Serial.print("Do am: "); Serial.print(h); Serial.print(" % \t");

__Serial.print("Nhiet do: "); Serial.print(t); Serial.println(" *C");

}
