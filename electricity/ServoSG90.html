Thông tin sơ bộ về SG90:

Thông tin cơ bản:

\(\bullet\) Điện áp hoạt động: 5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân motor-arduino)

- Cực âm(dây màu nâu) nối với chân GND của arduino

- Cực dương(dây màu đỏ) nối với chân GND của arduino

- Chân signal(dây màu vàng) nối với chân 9(hoặc bất kì chân PWM nào, tức chân digital có dấu ngã)

- Tải thư viện: bấm vô Tools \(\rightarrow\) Manage Libraries \(\rightarrow\) tra thư viện tên "Servo" của tác giả "Michael" \(\rightarrow\) Install

- Code mẫu:

#include <Servo.h>

// Khởi tạo đối tượng Servo để điều khiển

Servo myServo;

// Biến lưu vị trí góc quay của Servo

int pos = 0;

void setup() {

__// Khai báo chân tín hiệu của Servo nối vào chân Digital 9 trên Arduino

__myServo.attach(9);

}

void loop() {

__// Cho Servo quay từ 0 độ đến 180 độ

__// Không bắt buộc nhét vô for, cái này chỉ để nó quay từ tốn thôi

__for (pos = 0; pos <= 180; pos += 1) {

____myServo.write(pos);

____delay(15);

__}

__// Cho Servo quay ngược từ 180 độ về lại 0 độ

__for (pos = 180; pos >= 0; pos -= 1) {

____myServo.write(pos);

____delay(15);

__}

__delay(1000);

}
