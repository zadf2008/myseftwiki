Thông tin sơ bộ về LCD1602A Ver5.5/I2C:

Thông tin cơ bản:

\(\bullet\) Đây là 1 LCD tích hợp bộ chuyển đổi I2C

\(\bullet\) Điện áp hoạt động: 5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Nếu đèn không hiện thì đằng sau có 1 cái biến trở(cục màu xanh dương) vặn đấy là được.

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân cảm biến-arduino)

- Chân SDA nối vô chân A4(bắt buộc phải là chân này)

- Chân SCL nối vô chân A5(bắt buộc phải là chân này)

- Cực dương(VCC) nối với đầu 5V

- Cực âm(GND) nối với đầu GND

- Tải thư viện: bấm vô Tools \(\rightarrow\) Manage Libraries \(\rightarrow\) tra thư viện tên "LiquidCrystal I2C" của tác giả "Frank de Brabander" \(\rightarrow\) Install

- Code mẫu:

#include <Wire.h> // Thư viện I2C có sẵn của Arduino

#include <LiquidCrystal_I2C.h> // Thư viện LCD I2C vừa cài

// Khởi tạo màn hình LCD với địa chỉ I2C phổ biến là 0x27, 16 cột và 2 dòng, đôi lúc là địa chỉ 0x3F

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {

__lcd.init(); // Khởi tạo màn hình LCD

__lcd.backlight(); // Bật đèn nền phía sau màn hình

__// In dòng chữ đầu tiên ở vị trí Cột 0, Dòng 0

__lcd.setCursor(0, 0);

__lcd.print("XE DO DUONG R3");

__// In dòng chữ thứ hai ở vị trí Cột 0, Dòng 1

__lcd.setCursor(0, 1);

__lcd.print("SANCAP KET NOI!");

}

void loop() {

__// Không cần xử lý gì lặp lại trong loop cho bài test này

}

Một số lệnh khác của thư viện LiquidCrystal_I2C.h:

lcd.clear(): Xóa toàn bộ chữ trên màn hình và đưa con trỏ về góc trên cùng bên trái

lcd.home(): Đưa con trỏ về vị trí góc (0,0) nhưng KHÔNG xóa chữ hiện tại

lcd.backlight(): Bật đèn nền phía sau màn hình (màn hình sáng lên)

lcd.noBacklight(): Tắt đèn nền (chữ vẫn còn nhưng tối thui, dùng để tiết kiệm điện cho pin xe)

lcd.noDisplay(): Ẩn toàn bộ chữ trên màn hình (đèn nền vẫn sáng)

lcd.display(): Hiện lại chữ đã bị ẩn bởi lệnh noDisplay()
