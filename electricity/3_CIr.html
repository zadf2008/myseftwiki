Thông tin sơ bộ về 3_CIr:

Thông tin cơ bản:

\(\bullet\) Đây là 1 con đo khoảng cách 1 vật thể bằng cách đo thời gian sóng âm dội về

\(\bullet\) Điện áp hoạt động: 5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân cảm biến-arduino)

- chân R nối với chân 9(hoặc bất kì con chân PWM hay chân digital có dấu ~ nào của arduino)

- chân G nối với chân 10(hoặc bất kì con chân PWM hay chân digital có dấu ~ nào của arduino)

- chân B nối với chân 11(hoặc bất kì con chân PWM hay chân digital có dấu ~ nào của arduino)

- Cực âm(-) nối với đầu GND

- Code mẫu:

// Định nghĩa các chân điều khiển màu LED RGB (Yêu cầu chân PWM)

const int redPin = 9; // Chân điều khiển màu Đỏ

const int greenPin = 10; // Chân điều khiển màu Xanh lá

const int bluePin = 11; // Chân điều khiển màu Xanh dương

void setup() {

__pinMode(redPin, OUTPUT);

__pinMode(greenPin, OUTPUT);

__pinMode(bluePin, OUTPUT);

}

void loop() {

__// Bật màu Đỏ đơn thuần

__setColor(255, 0, 0); // Giá trị từ 0 đến 255

__delay(1000);

__// Bật màu Xanh lá đơn thuần

__setColor(0, 255, 0);

__delay(1000);

__// Trộn Đỏ và Xanh dương để tạo ra màu Tím

__setColor(150, 0, 255);

__delay(1000);

}

// Hàm tự định nghĩa để xuất độ sáng cho 3 màu cơ bản

void setColor(int red, int green, int blue) {

__analogWrite(redPin, red);

__analogWrite(greenPin, green);

__analogWrite(bluePin, blue);

}
