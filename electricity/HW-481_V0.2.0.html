Thông tin sơ bộ về Điện trở:

Thông tin cơ bản:

\(\bullet\) Đây là 1 con cảm biến đo cả độ ẩm và nhiệt độ trong không khí

\(\bullet\) Dải đo nhiệt độ: từ 0-50\(^oC\) (sai số \(\pm\)2%)

\(\bullet\) Dải đo độ ẩm: từ 20-90% RH (sai số \(\pm\)5%)

\(\bullet\) Điện áp hoạt động: 3.3-5V

\(\bullet\) Không cần gắn thêm điện trở

\(\bullet\) Sơ đồ nối chân cơ bản(giữa chân cảm biến-arduino)

- S(chân Signal ngây bên trái) nối với chân 2(hoặc bất kì chân digital nào của arduino)

- Cực dương(ở giữa) nối với đầu 5V

- Cực âm(bên phải) nối với đầu GND

- Tải thư viện: bấm vô Tools \(\rightarrow\) Manage Libraries \(\rightarrow\) tra thư viện tên "DHT sensor library" của tác giả "Adafruit" \(\rightarrow\) Install

- Code mẫu:

#include "DHT.h"

#define DHTPIN 2 // Khai báo chân Signal nối với chân Digital 2 trên Arduino

#define DHTTYPE DHT11 // Khai báo đang dùng cảm biến loại DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {

__Serial.begin(9600);

__dht.begin(); // bắt đầu đọc cảm biến

}

void loop() {

__delay(2000); // Phải delay lâu tại cảm biến này đọc không được nhanh lắm

__float do_am = dht.readHumidity(); // đo độ ẩm

__float nhiet_do = dht.readTemperature(); // đo nhiệt độ

__if (isnan(do_am) || isnan(nhiet_do)) {

____Serial.println("Lỗi");

____return;

__}

__Serial.print("Độ ẩm: ");

__Serial.print(do_am);

__Serial.print(" % \t");

__Serial.print("Nhiệt độ: ");

__Serial.print(nhiet_do);

__Serial.println(" *C");

}
