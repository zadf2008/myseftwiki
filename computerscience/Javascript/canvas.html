Vẽ canvas

Các lệnh vẽ:

\(\bullet\) getContext("2d"): Khởi tạo chế độ vẽ 2D trên canvas.

\(\bullet\) fillStyle = "màu": Chọn màu tô đặc cho hình vẽ.

\(\bullet\) strokeStyle = "màu": Chọn màu cho đường viền hoặc nét vẽ.

\(\bullet\) lineWidth = số_pixel: Thiết lập độ dày cho nét vẽ.

\(\bullet\) fillRect(x, y, w, h): Vẽ một hình chữ nhật đặc.

\(\bullet\) gr.shadowColor: Màu bóng.

\(\bullet\) gr.shadowBlur: Độ nhòe bóng.

\(\bullet\) gr.shadowOffsetX: Vị trí bóng theo trục hoàng.

\(\bullet\) gr.shadowOffsetY: Vị trí bóng theo trục tung.

\(\bullet\) strokeRect(x, y, w, h): Vẽ một khung viền hình chữ nhật.

\(\bullet\) clearRect(x, y, w, h): Xóa sạch một vùng hình chữ nhật.

\(\bullet\) beginPath(): Bắt đầu một đường nét vẽ mới độc lập.

\(\bullet\) moveTo(x, y): Di chuyển đầu bút đến tọa độ mới mà không vẽ.

\(\bullet\) lineTo(x, y): Kéo một nét thẳng từ vị trí hiện tại đến tọa độ mới.

\(\bullet\) arc(x, y, r, sAngle, eAngle): Tạo một đường cong hoặc hình tròn.

- Code:

const canvas2 = document.getElementById("canvas2");

const ctx2 = canvas2.getContext("2d");

----

ctx2.beginPath();

ctx2.fillStyle = 'white';

ctx2.arc(50, 100, 15, 0, 2 * Math.PI);------<!-- Math.PI tương đương số pi trong toán học -->

ctx2.fill();

ctx2.strokeStyle = 'red';

ctx2.lineWidth = 5;

ctx2.stroke();

\(\bullet\) stroke(): Thực hiện vẽ đường viền theo các nét đã vạch.

\(\bullet\) fill(): Thực hiện tô màu đặc vào vùng không gian kín của nét vẽ.

\(\bullet\) font = "cấu_hình": Thiết lập font và kích thước cho chữ.

\(\bullet\) fillText("văn_bản", x, y): Viết chữ đặc lên canvas.

- Code:

const canvas1 = document.getElementById("canvas1");

const ctx = canvas1.getContext("2d");

----

ctx.beginPath();

ctx.fillStyle = '#ffffff';

ctx.font = "50px Arial";

ctx.fillText("content", 50, 100);

\(\bullet\) strokeText("văn_bản", x, y): Viết chữ dạng viền rỗng ruột.

ctx.strokeStyle = "#ffffff";

ctx.font = "20px Arial";

ctx.strokeText("Hi", 10, 30);

\(\bullet\) drawImage(img, x, y): Chèn một hình ảnh vào canvas.

const img = document.getElementById("myImage");

ctx.drawImage(img, 0, 0);
