\(\bullet\) Các lệnh javascript có thể được dùng trong <script></script> hoặc trong file .js và được để trong <script src="file.js"></script>

\(\bullet\) Thông thường nên để ở cuối thẻ body ngay sau thẻ đóng để lệnh dễ bắt lấy được sự kiện hơn

Khái niệm về hàm:

\(\bullet\) const là hàm không thể thay đổi

\(\bullet\) let là hàm có thể thay đổi

Ví dụ:

const admin = { name: "zadf2008", age: 18 };

----

admin = { name: "zadf2007", age: 17 };-----// lỗi nên khi để ở đây chỉ để minh họa, không nên đưa vào

----

admin.age = 20;----------------------------// hợp lệ

alert(admin.age);--------------------------// in ra 20

Ví dụ trên chỉ là code mẫu, để lệnh thật sự chạy, phải có lệnh gọi hàm, đây là code dùng để chạy:

<button onclick="chaylenh()">content</button>
