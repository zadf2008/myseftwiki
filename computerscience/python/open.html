open

\(\bullet\) Có tác dụng mở file và thao tác file

\(\bullet\) Có 4 chế độ cơ bản:

- r: có tác dụng đọc file, nếu không có file thì sẽ bị lỗi

- a: có tác dụng ghi thêm vô file

- w: có tác dụng ghi đè vô file, nếu không có file thì tự tạo file mới, nếu có file và trong file có nội dung thì file sẽ bị xóa và ghi lại

- x: tạo ra một file mới, nếu file tạo đã có thì sẽ bị lỗi

- r+: đọc và ghi

- w+: đọc và xóa đi ghi lại

- a+: đọc và ghi thêm

\(\bullet\) Các lệnh thao tác:

- read(size): đọc từ vị trí con trỏ chuột đến hết toàn bộ file, nếu chuyền thêm thông số size thì đọc theo số kí tự(hoặc số bytes) (cho chế độ: r, r+, w+, a+)

- readline(): chỉ đọc duy nhất một dòng tính từ vị trí con trỏ (cho chế độ: r, r+, w+, a+)

- readlines(): đọc toàn bộ file và chia các dòng thành một danh sách (cho chế độ: r, r+, w+, a+)

- write(string): ghi 1 chuỗi kí tự và không tự động xuống dòng, dùng "\n" để xuống dòng ( cho chế độ: a, x, w, a+, x+, w+)

- writelines([danh sách chuỗi]): ghi cả 1 danh sách các chuỗi kí tự và không tự động xuống dòng, dùng "\n" để xuống dòng ( cho chế độ: a, x, w, a+, x+, w+)

- tell(): trả về vị trí con trỏ

- seek([vị trí]): điều khiển vị trí con trỏ

\(\bullet\) Ví dụ:

with open("text.txt", "w+", encoding="utf-8") as f:

----print(f.tall())

----f.seek(0)

----read = f.read()
