\(\bullet\) Với a = [0, 2, 1, 4], ta có các lệnh tương tác:

- a[1]

Kết quả: 2

- sorted(a)

Kết quả: [0, 1, 2, 4]

- b = a.copy()

Kết quả: b = [0, 2, 1, 4]

- Với danh sách b = [5, 7, 2], ta kết hợp bằng a.extend(b)

Kết quả: [0, 2, 1, 4, 5, 7, 2]

- a.append(5)
Kết quả: a = [0, 2, 1, 4, 5]
- a.insert(2, 9)
Kết quả: a = [0, 2, 9, 1, 4]
- a.remove(2)
Kết quả: a = [0, 1, 4]
- a.pop()
Kết quả: 4 (danh sách còn lại: a = [0, 2, 1])
- a.clear()
Kết quả: a = []
- len(a)
Kết quả: 4
- a.index(1)
Kết quả: 2
- a.count(2)
Kết quả: 1
- a.reverse()
Kết quả: a = [4, 1, 2, 0]
- a.sort()
Kết quả: a = [0, 1, 2, 4]

a[1:3]

Kết quả: [2, 1, 4]

a[-2:]

Kết quả: [1, 4]
