\(\bullet\) Đầu tiên cần tải thư viện trước:

- Bật terminal và gõ: pip install numpy

- Gọi thư viện:

import numpy as np --------#as đổi tên thư viện

Các lệnh thống kê cơ bản:

\(\bullet\) np.mean([danh sách]): tính giá trị trung bình

\(\bullet\) np.median([danh sách]): tính số trung vị

\(\bullet\) np.var([danh sách]): tính phương sai

\(\bullet\) np.std([danh sách]): tính độ lệch chuẩn

\(\bullet\) np.ptp([danh sách]): tính độ biến thiên

\(\bullet\) np.min([danh sách]): tìm giá trị nhỏ nhất trong sanh sách

\(\bullet\) np.max([danh sách]): tìm giá trị lớn nhất trong sanh sách

\(\bullet\) np.percentile([danh sách], q): tính đường phân vị thứ q(từ 0 đến 100)

\(\bullet\) np.quantile([danh sách], q): tính phân vị thứ q(từ 0 đến 1)

\(\bullet\) np.sum([danh sách]): tính tổng tất cả các phần tử

\(\bullet\) np.prod([danh sách]): tính tích tất cả các phần tử

\(\bullet\) np.cumsum([danh sách]): tính tổng tích lũy tất cả các phần tử

\(\bullet\) np.bincount([danh sách]): đếm các số không âm
