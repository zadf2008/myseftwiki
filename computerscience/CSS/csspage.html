Các cách sài css

\(\bullet\) file chứa lệnh css có đuôi .css, để dùng được ta ghi ở thẻ trong cặp thẻ head:

- <link rel="stylesheet" href="file.css">

\(\bullet\) để style="...", ví dụ:

- <p style="color: red">

\(\bullet\) để trong cặp thẻ style trong thẻ cặp thẻ head, ví dụ:

<head>

----<style>

--------nav {-----------------/* chọn thẻ để định dạng */

------------color: red;

--------}

----

--------table thead tr th {---/* chọn vị trí thẻ để định dạng */

------------color: red;

--------}

----

--------.tenclass {-----------/* tạo 1 class */

------------color: red;

--------}

----</style>

</head>

- Cách dùng class: <p class="tenclass">content</p>

Các kiểu gán màu:

\(\bullet\) rgb(red, blue, green)

\(\bullet\) rgba(red, blue, green, gradient)

\(\bullet\) loại chữ, VD: red; blue; green;...

\(\bullet\) id màu, VD: #ffffff; #1f2
