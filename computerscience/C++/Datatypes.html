Cách dùng [kiểu dữ liệu] [tên biến] = ...; sau đây là các kiểu dữ liệu trong c++:

\(\bullet\) short: kiểu dữ liệu số nguyên, kích thức 2 bytes(phạm vi từ -32,768 đến 32,767)

\(\bullet\) unsigned short: kiểu dữ liệu số nguyên dương, kích thước 2 bytes(phạm vu từ 0 đến 65,535)

\(\bullet\) int: kiểu dữ liệu số nguyên, kích thước 4 bytes(phạm vi từ -2,147,483,648 đến 2,147,483,647)

\(\bullet\) unsigned int: kiểu dữ liệu số nguyên dương, kích thước 4 bytes tương đương 32-bit(phạm vi từ 0 đến 4,294,967,295, hậu tố là U)

\(\bullet\) long: kiểu dữ liệu số nguyên:

- Window: kích thước 4 bytes(phạm vi từ -2,147,483,648 đến 2,147,483,647)

- Linux và macOS: kích thước 8 bytes bytes(phạm vi từ -9,223,372,036,854,775,808 đến 9,223,372,036,854,775,807)

\(\bullet\) unsigned long: kiểu dữ liệu số nguyên dương:

- Window: kích thước 4 bytes(phạm vi từ 0 đến 4,294,967,295)

- Linux và macOS: kích thước 8 bytes8 bytes(phạm vi từ 0 đến 18,446,744,073,709,551,615)

\(\bullet\) long long và unsigned long long: cũng là kiểu dữ liệu số nguyên, kích thước 8 bytes, phạm vi như trên(hậu tố của long long là LL và unsigned long long là ULL)

\(\bullet\) float: kiểu dữ liệu phân số, kích thước 4 bytes, chính xác đến 7 chữ số phía sau

- tuy nhiên C++ coi mọi phân số là double nên khi dùng float nên dùng hậu tố f, chẳng hạn float pi = 3.14f;

\(\bullet\) double: kiểu dữ liệu phân số, kích thước 8 bytes, chính xác đến 15 chữ số phía sau

\(\bullet\) long double: kiểu dữ liệu phân số, kích thước 8 bytes, 12 bytes hoặc 16 bytes chính xác đến 19 chữ số phía sau trở lên

- Tuy vậy hầu hết các máy tính hiện nay đều chỉ dừng lại mức 8 bytes như double vì độ chính xác 15 chữ số thập phân phía sau là quá đủ cho các công việc tính toán và tối ưu được tốc độ tính toán

- Hậu tố để ép số thực về dạng long double là L

\(\bullet\) bool: kiểu dữ liệu true/false

\(\bullet\) char: kiểu dữ liệu lưu duy nhất 1 ký tự, và để trong dấu ''(ví dụ char tu1 = 'a')

\(\bullet\) const char*: kiểu dữ liệu lưu 1 chuỗi ký tự, và để ""(ví dụ const char* doan1 = "caigido")

\(\bullet\) auto: kiểu tự nhận diện kiểu dữ liệu, phải gắn giá trị ngay trong dòng đó và không thể thay đổi kiểu dữ liệu

\(\bullet\) struct: kiểu tập hợp các kiểu dữ liệu, vd:

#include <iostream>

using namespace std;

____

// đặt struct ở bên ngoài để hàm nào cũng có thể dùng được

struct cpp {

__const int a = 10;__//const có tác dụng cấm cho biến đó không thể thay đổi

__const char* b = "zadf2008";

__int c = 11;

};

____

int main() {

__cpp bien1;_____//tạo một biến từ struct cpp

__bien1.c = 12;__//thay đổi giá trị biến trong struct

__cout << bien1.a << "\n"

__cout << bien1.b << "\n"

__cout << bien1.c << "\n"

__

__return 0;

}
