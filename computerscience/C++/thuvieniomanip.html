\(\bullet\) Thư viện chuyên xử lí định dạng, và kiểu dữ liệu

Ví dụ 1 (định dạng số, hệ cơ số, làm tròn, độ rộng):

#include <iostream>

#include <iomanip>

____

int main() {

__double pi = 3.1415926535;

__int x = 42;

____

__std::cout << std::setprecision(5) << pi << std::endl;__//hiển thị 5 chữ số có nghĩa

__std::cout << std::fixed << std::setprecision(5) << pi << std::endl;__//hiển thị 5 chữ số sau dấu thập phân

__std::cout << std::scientific << 75345.092384 << std::endl;__//hiển thị số thực dưới dạng khoa học

____

__std::cout << std::setw(10) << std::setfill('*') << std::right << x << "\n";__//độ rộng 10 kí tự, căn phải, lấp khoảng trống bằng *

__std::cout << std::setw(10) << std::setfill('.') << std::left << x << "\n";__//độ rộng 10 kí tự, căn trái, lấp khoảng trống bằng .

__std::cout << std::setw(15) << std::setfill('.') << "Hello world" << "\n";

____

__std::cout << std::setbase(10) << 20 << "\n";__//chọn hệ cơ số 10

____

__return 0;

}

Ví dụ 2(ngày và giờ):

____

__std::cout << "\n";

Các thành viên của std::tm:

tm_sec: giây (thường từ 0 đến 60, có thể có giây nhuận).

tm_min: phút (từ 0 đến 59).

tm_hour: giờ (từ 0 đến 23).

tm_mday: ngày trong tháng (từ 1 đến 31).

tm_mon: tháng (từ 0 đến 11; tháng 1 là 0, tháng 12 là 11).

tm_year: số năm tính từ năm 1900 (năm 2026 có giá trị 126).

tm_wday: thứ trong tuần (từ 0 là Chủ Nhật đến 6 là Thứ Bảy).

tm_yday: ngày trong năm (từ 0 đến 365; ngày đầu năm là 0).

tm_isdst: thông tin về giờ mùa hè; giá trị lớn hơn 0 nếu đang áp dụng, bằng 0 nếu không áp dụng, nhỏ hơn 0 nếu không xác định.

Lưu ý: tm_sec có thể bằng 60 để biểu diễn giây nhuận trong những trường hợp phù hợp.

Ví dụ 3(cờ định dạng):

#include <iostream>

#include <iomanip>

____

int main() {

____

__std::setiosflags(std::ios_base::showpos | std::ios_base::uppercase);__//bật dấu + và chữ in hoa

__std::cout << 42 << " " << std::hex << 255 << "\n";

____

__std::resetiosflags(std::ios_base::showpos | std::ios_base::uppercase);__//tắt hai cờ trên

__std::cout << std::dec << 42 << " " << std::hex << 255 << std::dec << "\n";

____

__std::cout << std::showpos << 42 << std::noshowpos << std::endl;

__std::cout << std::uppercase << std::hex << 42 << std::nouppercase << std::dec << std::endl;

__std::cout << std::boolalpha << true << std::noboolalpha << std::endl;

__std::cout << std::showpoint << 42.0 << std::noshowpoint << std::endl;

__std::cout << std::showbase << std::hex << 42 << std::noshowbase << std::dec << std::endl;

____

return 0;

}

Các cờ định dạng của std::ios_base và manipulator tương ứng:

std::ios_base::showpos tương ứng với std::showpos; tắt bằng std::noshowpos.

std::ios_base::showbase tương ứng với std::showbase; tắt bằng std::noshowbase.

std::ios_base::showpoint tương ứng với std::showpoint; tắt bằng std::noshowpoint.

std::ios_base::uppercase tương ứng với std::uppercase; tắt bằng std::nouppercase.

std::ios_base::boolalpha tương ứng với std::boolalpha; tắt bằng std::noboolalpha.

std::ios_base::skipws tương ứng với std::skipws; tắt bằng std::noskipws.

std::ios_base::unitbuf tương ứng với std::unitbuf; tắt bằng std::nounitbuf.

std::ios_base::adjustfield là nhóm cờ căn chỉnh, gồm std::left, std::right và std::internal.

std::left: căn trái; std::right: căn phải; std::internal: chèn ký tự lấp vào giữa dấu của số và phần giá trị.

std::ios_base::floatfield là nhóm cờ định dạng số thực, gồm std::fixed và std::scientific.

std::fixed: hiển thị số thực theo dạng thập phân cố định.

std::scientific: hiển thị số thực theo dạng ký hiệu khoa học.

std::hex tương ứng với cờ cơ số std::ios_base::hex; std::dec tương ứng với std::ios_base::dec.

std::oct tương ứng với cờ cơ số std::ios_base::oct.

std::setbase(10) tương đương với std::dec (Decimal - hệ 10).

std::setbase(16) tương đương với std::hex (Hexadecimal - hệ 16).

std::setbase(8) tương đương với std::oct (Octal - hệ 8).

std::setbase(0): khi nhập số nguyên, cho phép tự nhận diện cơ số theo tiền tố của dữ liệu; khi xuất, không có tác dụng tương đương.

std::setprecision(n): đặt độ chính xác khi hiển thị số thực; ý nghĩa phụ thuộc vào chế độ định dạng số thực.

std::setw(n): đặt độ rộng trường cho lần xuất hoặc nhập kế tiếp.

std::setfill(c): đặt ký tự dùng để lấp khoảng trống trong trường định dạng.

std::setiosflags(flags): bật các cờ định dạng được chỉ định.

std::resetiosflags(flags): tắt các cờ định dạng được chỉ định.

std::endl: xuống dòng và đẩy dữ liệu trong bộ đệm ra luồng.

Lưu ý: std::skipws và std::noskipws chủ yếu ảnh hưởng đến thao tác nhập; std::unitbuf bật việc đẩy bộ đệm sau mỗi thao tác xuất, còn std::nounitbuf tắt chế độ này.
