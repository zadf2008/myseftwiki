\(\bullet\) Nhóm là tập hợp các hàm liên kết với nhau

\(\bullet\) Trong nhóm sẽ có 1 phần là private, nơi chứa biến mà chỉ hàm trog nhóm đó có thể thay đổi và in ra, bên ngoài không thể thay đổi trực tiếp

\(\bullet\) Trong nhóm sẽ có 1 phần là public, nơi chứa hàm và bên ngoài có thể gọi

Ví dụ:

#include <iostream>

____

class Createnewacc {

private:

__const char* name;

__int LV = 1;

__int HP = 100;

__int MP = 100;

public:

__void named(const char* inname) {

____name = inname;

____std::cout << "Hello " << inname << std::endl;

____return;

__}

____

__void call() {

____std::cout << "Name: " << name << std::endl;

____std::cout << "LV: " << LV << std::endl;

____std::cout << "HP: " << HP << std::endl;

____std::cout << "MP: " << MP << std::endl;

____return;

__}

};

____

int main() {

__Createnewacc acc1;

__acc1.named("zadf2008");

__acc1.call();

____

__return 0;

}
