\(\bullet\) Tác dụng kiểm tra điều kiện

\(\bullet\) Các kiểu so sánh:

== : so sánh bằng

!= : so sánh khác

>= : so sánh lớn hơn hoặc bằng

<= : so sánh bé hơn hoặc bằng

> : so sáng lớn hơn

< : so sánh bé hơn

|| : 1 trong các điều kiện đúng thì thỏa

&& : tất cả các điều kiện đúng thì mới thỏa

Cấu trúc điều kiện loại 1(kiểm tra tuần tự, thỏa 1 nhánh là kết thức):

if ([điều kiện 1]) {

__//khối lệnh

}

else if ([điều kiện 2]) {

__//khối lệnh

}

else if ([điều kiện 3]) {

__//khối lệnh

}

__...

else {

__//khối lệnh

}
